# Abacus AI Engineering Internship

Welcome to my repository for the Abacus AI Engineering Internship.

This repository contains my learning progress, assignments, and projects completed during the 6-week internship. The internship focused on developing practical AI Engineering skills, starting from Python foundations and gradually progressing towards Machine Learning, Deep Learning, Generative AI, and LLM-based application development.

The purpose of this repository is to document my learning journey and showcase the projects and assignments developed throughout the internship.

---

## Internship Roadmap

### Week 1: AI Engineering Introduction + Python Foundation

During the first week, the focus was on building a foundation in AI Engineering concepts and strengthening Python programming skills.

Topics covered:

* Introduction to AI and Generative AI
* AI Engineer role and responsibilities
* AI product development lifecycle
* Python fundamentals
* Data structures and functions
* File handling and JSON processing
* Object-Oriented Programming (OOP)
* Error handling and package management
* Working with APIs
* Structured Python project development

**Project: AI Document Processing System**

The project focused on:

* Reading and processing documents
* Extracting and storing information
* Applying OOP principles
* Handling errors
* Creating a structured Python project setup

---

### Week 2: Machine Learning + Deep Learning Fundamentals

The second week focused on understanding the fundamentals of Machine Learning and Deep Learning.

Topics covered:

* Python for Machine Learning
* NumPy and Pandas
* Dataset processing and cleaning
* Data visualization
* Statistics and probability basics
* Machine Learning workflow
* Supervised and unsupervised learning
* Model training and evaluation
* Introduction to neural networks
* Deep Learning fundamentals

**Project: ML Prediction System + Basic Neural Network**

The project focused on:

* Processing datasets
* Training Machine Learning models
* Building a basic neural network
* Evaluating model performance
* Generating predictions

---

### Week 3 & 4: Generative AI + LLM Application Development

The third and fourth weeks focused on understanding and developing applications using Generative AI and Large Language Models.

Topics covered:

* Generative AI fundamentals
* Large Language Models (LLMs)
* Transformers and tokenization
* Prompt engineering
* Working with LLM APIs
* Conversation history and API error handling
* Embeddings and semantic search
* Vector databases
* Retrieval Augmented Generation (RAG)
* Document-based question answering
* Introduction to AI agents

**Project: AI Knowledge Assistant**

The project focused on:

* Document upload and processing
* Creating embeddings
* Storing document embeddings in a vector database
* Retrieving relevant information
* Generating answers using an LLM
* Implementing a basic RAG workflow
* Providing source references with generated responses

> **Note:** Week 3 and Week 4 work is organized together under the `Week-03/` folder.

---

### Week 5 & 6: Computer Vision + Object Detection Theory

The fifth and sixth weeks focused primarily on the theoretical foundations of Computer Vision, image processing, and object detection.

Topics covered:

* Introduction to Computer Vision
* Digital images and image representation
* Image preprocessing techniques
* Image transformations
* Image classification concepts
* Convolutional Neural Networks (CNNs)
* CNN architecture and working principles
* Object detection fundamentals
* Bounding boxes and confidence scores
* Intersection over Union (IoU)
* YOLO object detection concepts
* YOLO detection workflow
* Custom object detection workflows
* Dataset collection and preparation
* Image annotation and labeling
* Training and validation datasets
* Image preprocessing and augmentation
* Model training and evaluation concepts
* Object detection evaluation
* Color detection and image segmentation
* Basic Computer Vision pipelines
* Integration of Computer Vision components into AI applications

The focus during these weeks was on developing a theoretical understanding of Computer Vision and object detection concepts and how they can be applied to practical AI systems.
